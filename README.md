# 🎨 Emoji Recognizer

|:---|:---|
| 😊 Happy | ❤️ Heart |
| 😢 Sad | ⭐ Star |
| 😠 Angry | 👍 Thumbs Up |
| 😮 Surprise | ☀️ Sun |
| 😐 Neutral | |
| 😍 Love | |

---

### 1. How to run this app

```bash
# Backend
cd backend #Copy đường dẫn trong File Explorer của bạn
pip install -r requirements.txt
python run.py

# Frontend
cd frontend #Copy đường dẫn trong File Explorer của bạn
npm install
npm run dev
```
App chạy tại: http://localhost:5173
